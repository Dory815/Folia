# Common Styles and StyleJson source/member ledger

This packet ports only the two pinned utility classes. It does not establish
CommonWrapper, layout, scene, SVG, or Folia output parity.

| Pinned source member | Native implementation | Source obligation |
| --- | --- | --- |
| Styles constructor, parse | styles.cpp | New style record first; newline replacement; comment removal; capturing split behavior; stop at the first invalid prefix; call set for each parsed pair. |
| pattern, connect | styles.ixx, styles.cpp | Retain ordered Source keys, exact regex text/flags, connection children/parts, callable names, and base Styles.connect selection. TRBL and WSC are module exports. |
| sanitizeValue | styles.cpp | Consult the current class-level pattern table; preserve Source replacement, escaped-character removal, quote balancing, and malformed values. |
| cssText, styleList | styles.cpp | Preserve own-key order and Source filtering; styleList is a distinct shallow copy. |
| set, get, setStyle | styles.cpp | Camel-case conversion operates on UTF-16 code units; string/number/boolean values use Source formatting; sanitize and split before empty-value deletion; get is own-property based. |
| combineParent, combineChildren, parentName, childName, normalizeName | styles.cpp | Preserve dash traversal, subpart naming, base static connection lookup, deletion, and exact normalization. |
| splitSpaces, splitTRBL, combineTRBL, splitSame, combineSame, splitWSC, combineWSC, splitFont, saveFontParts, combineFont, combinePart | styles.cpp | Preserve capturing-split gaps, source rule order, TRBL/WSC propagation, font recognition order, and the intentionally empty font recombination. |
| StyleJsonSheet constructor, addStyles | style_json.cpp | Default/explicit null behavior; own enumerable key order; shallow selector-property copies; nested value aliases; Source Object.assign behavior for nullish sources. |
| removeStyles, clear | style_json.cpp | Delete requested selectors in order; clear by rebinding to a new record. |
| cssText, getStyleString, getStyleRules, getStyleDefString | style_json.cpp | Preserve method dispatch, nested rule recursion, indentation, own-key order, primitive stringification, and explicit-null errors. |

The pinned source hashes are recorded in
docs/math-port/common-styles-work-plan.md. Root's frozen original corpus is
build/math-port/common-styles-original.json, generated by
tools/math-port/common-styles-original-oracle.cjs. It includes the 37th
derived-class row, where a live class-owned pattern table is supplied to the
protected Styles(cssText, classPatterns) constructor before parsing. The table
must be owned by the actual class descriptor or a module static and outlive
each instance; passing a temporary is invalid. C++ base-constructor virtual
dispatch is not used to infer the derived class.

The native observer ran all 37 frozen rows against the locked original CJS
classes; strict comparison matched every row (gate 21). The focused native
tests passed 19 assertions across 6 tests. This verifies the bounded typed
Styles/StyleJson behavior represented by this corpus; it does not establish
Context constructor/prototype binding, CommonWrapper/layout, SVG, or complete
Folia integration. Copying a native Styles or StyleJsonSheet object is
disabled so a C++ copy cannot masquerade as a distinct Source instance
sharing the same record.

The capturing splitSpaces host adapter uses the actual Source regex and
reconstructs the String.split capture/gap array before applying the source
shift/push loop. It must be checked against the frozen high-level CSS records,
especially repeated/leading/trailing whitespace, tabs/CR, comma-space, and
unclosed quotes. This packet does not claim a browser CSS parser.

For every Styles snapshot, serialize cssText, the complete ordered styleList,
its Object.keys order, missing lookup, four padding lookups, and the nested
border-side/property lookup matrix. Mutation rows retain each intermediate
snapshot. The copy row records distinct StyleList handles and the unchanged
Styles value. The protected-method row serializes every returned UTF-16 name
and sanitized value. The derived row must construct with the descriptor-owned
custom patterns before the first parse, then observe base Styles.connect.

The stylesheet lifecycle row observes rendered text and nested rules before
and after mutating the original outer selector record and nested child record;
it also checks shallow property copying, nested alias identity, add/remove,
clear/rebind, and null input. The static row observes the exported TRBL/WSC
arrays, each regex's exact source and flags, connection key order, children,
parts (including undefined), subPart (including undefined), and split/combine
function names. The observer may not infer these fields from the input or
reconstruct the style table from CSS text.
