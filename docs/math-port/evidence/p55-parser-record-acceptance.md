Configuration Context records directly. Property and Context inputs feed the
same class-owned reducers and registry; no copied configuration graph or second
callable body is introduced. Label and TagInfo implement their complete actual
constructors, including all eight TagInfo parameters in Source field order.
TagFormat array handles retain their original identity and live contents.

independent Luna reviews inspected MapHandler, NodeFactory and tag records.

before acceptance: own-property deletion revealing a prototype value, a slice

before Upper Has during reverse. Each original extension failed the previous
body before correction. Their red logs are listed in the P55 freeze document.

It executes the locked actual MapHandler, CharacterMap, NodeFactory, Label and
TagInfo CJS classes and verifies TS clone/npm equality and all Source/CJS hashes.

canonical callable identities. No fake TeX parser/jax/configuration is used.

original assertions, exit 1. The correct baseline and restored implementation
both pass 27 assertions in 27 tests, exit 0. Gold remains byte-identical during
fault injection. The original optional-receiver harness timeout is excluded;
