## Exact predicate behavior and the 75 sparse cases

All three `mrow` predicates iterate the array with JavaScript `for...of`; none uses `Array.some`, `every`, or `forEach`. The iterator is created from the current `childNodes` array when the loop begins. It retains that array object if a callback rebinds the node's `childNodes`, while in-place edits to the captured array affect subsequent iteration. Array holes are yielded as `undefined`; they are not skipped by `for...of`.

* `AbstractMmlNode.isEmpty` (TS 547–552) executes `for (const child of this.childNodes) { if (child && !child.isEmpty) return false; } return true`. It skips any falsey yield (including a hole/Undefined and Null), reads `isEmpty` only on truthy children, and short-circuits on the first non-empty child. A null/non-iterable `childNodes` fails when iteration begins. Since `MmlMrow` does not override this member, the `mrow-isEmpty-*` cases exercise this base method.
* `AbstractMmlTokenNode.isEmpty` (TS 1040–1048) has different rules: each yield must satisfy actual `instanceof TextNode`, or it immediately returns false; only then does it call `child.getText()` and test its string length. A hole/Undefined/Null therefore returns false, not the base method's skip behavior. No kind-name test is an equivalent to the source class-identity check. Empty text nodes allow iteration to continue; a nonempty text node short-circuits false.
* `MmlMrow.isSpacelike` (TS 57–66) reads `child.isSpacelike` unconditionally for every yield and returns false at the first false value; it returns true only after iteration completes. Consequently, a hole or Undefined throws while reading `isSpacelike`, and explicit Null throws the corresponding null-property TypeError. A preceding non-spacelike child returns false before a later bad slot is visited.
* `MmlMrow.isEmbellished` (TS 72–89) keeps a local `embellished` flag and an index. It skips falsey yields. For a truthy child it first reads `child.isEmbellished`: a second embellished child immediately returns false; the first sets the flag and writes `_core = i`. If the child is not embellished, it then reads `child.isSpacelike`, returning false if that is false. The loop increments `i` once per yielded slot, including falsey slots. It returns the flag after a complete pass. It does not reset `_core` at entry; an early return can leave a previous core index or the index set by the first embellished child.

The 75 Source299 cases are exactly 25 three-slot shapes × these three predicates. The first two slots range over hole (`H`), Undefined (`U`), Null (`N`), node `a`, or node `b`; the final slot is always node `c`. In this generator, all three labels `a`, `b`, and `c` are independently created with `factory.create('mi')` (`sparse-mml-oracle.cjs`, lines 25–26); none is an `mo`. These `mi` leaf nodes have empty children. The separate Return32 oracle deliberately creates `a` as `mi`, `b` as `mo`, and `c` as `mi` (`sparse-mml-return-oracle.cjs`, line 17); do not use its `mo` to characterize the 75 predicate rows. The frozen outcomes are:

| Predicate | Cases | Outcome summary | Why it distinguishes the methods |
|---|---:|---|---|
| `mrow-isEmpty-*` | 25 | All `true`, no errors | Base method skips falsey slots and all present leaves are empty. |
| `mrow-isSpacelike-*` | 25 | 15 errors, 10 `false` | The 15 shapes whose first slot is H/U/N error immediately on that slot; the ten starting with `a` or `b` return false at slot zero before later slots. |
| `mrow-isEmbellished-*` | 25 | All `false`, no errors | Falsey slots are skipped; present `a`/`c` leaves are non-embellished and non-spacelike, so every shape eventually returns false. No null dereference is implied by those results. |

Thus a common helper that silently skips holes/nulls for all three methods would diverge. So would treating the `isSpacelike` error cases as boolean false, or adding a falsey guard to its source loop.

## Raw `core`, `coreMO`, and `notParent` observations

`p23b-sparse-mml-return-source.json` contains 32 cases from `sparse-mml-return-oracle.cjs`. Its scenarios are actual `MmlFactory`/registered node instances. The `H`, `U`, `N`, and `a` outputs are tags for hole/Undefined, explicit Null, and a node identity. They are source distinctions, not aliases for a null C++ pointer.

| Cases | Source member | Results and control flow |
|---|---|---|
| 4 `mstyle-core-*`, 4 `mstyle-coreMO-*` | `AbstractMmlLayoutNode.core/coreMO` (MmlNode.ts 1139–1147), reached through actual `MmlMstyle` | `core()` returns `childNodes[0]` raw: H and U return Undefined, N returns Null, `a` returns that node identity. `coreMO()` calls `childNodes[0].coreMO()` directly: H/U throw “reading 'coreMO'” from undefined, N throws from null, and `a` dispatches to and returns the node's coreMO result. |
| 4 `mfrac-core-*`, 4 `mfrac-coreMO-*` | `AbstractMmlBaseNode.core/coreMO` (MmlNode.ts 1185–1193), reached through actual `MmlMfrac` | Same raw-return and direct-call distinction as layout nodes. `core()` preserves H/U versus N; `coreMO()` dereferences and throws for each absent/nullish slot. |
| 8 `mrow-core-getter-rebind-*`, `mrow-coreMO-getter-rebind-*` | `MmlMrow.core/coreMO` (mrow.ts 95–110) | Return32's distinct fixture creates `a` as `mi`, `b` as `mo`, and `c` as `mi`. A test-installed `isEmbellished` getter first invokes the original getter on initial `[b]` (setting `_core=0` and returning true), records that call, then rebinds `childNodes` to `[H]`, `[U]`, `[N]`, or `[a]`. `core()` evaluates the virtual getter before looking up the current slot, and returns U/U/N/`a`. `coreMO()` does the same re-read and then calls the current value's `coreMO`, producing undefined/null property errors for H/U/N and returning `a` for the node. It must not cache the old `[b]` child or the pre-getter array. This is positive getter/core-index evidence from Return32 only; the 75 Source299 predicate cases never produce `isEmbellished === true` and do not demonstrate a successful predicate-driven core-cache update. |
| 8 `mstyle-notParent-*` and `mstyle-notParent-flag-length-*` | `MmlMstyle.notParent` (mstyle.ts 59–61) | The getter is `this.childNodes[0] && this.childNodes[0].childNodes.length === 1`. For H/U it returns raw Undefined; for N raw Null; for the tested `a` with zero children it returns boolean false. The paired `flag-length` rows add a second child to the *mstyle array* and preserve the same result, confirming the predicate checks the first child's child count. The source expression reads slot zero for the truthiness test and, when truthy, reads slot zero again for `.childNodes.length`; it is not a boolean getter over mstyle's own length. |

The remaining relevant source defaults clarify callers: `AbstractMmlNode.core()` and `coreMO()` return `this` (MmlNode.ts 650–661); `AbstractMmlNode.notParent` returns false (586–588); `AbstractMmlEmptyNode` returns self for core/coreMO and false for notParent (TS 1257–1362); `MmlInferredMrow.notParent` returns true (mrow.ts 214–216). `AbstractMmlNode.Parent` (MmlNode.ts 577–582) tests `parent && parent.notParent` using JavaScript truthiness, so the potentially raw Undefined/Null result from `MmlMstyle.notParent` is semantically significant and must be interpreted at that call site, not normalized in the getter. The typed native return is already `Property` for `notParent` and `NodeValue` for `core/coreMO`; retaining Undefined versus Null is necessary to match these fixtures.

## Current native boundary and uncovered cases

Current declarations retain these distinct return domains in `src/math/core/mml_tree/mml_node.ixx`: `bool isEmpty/isSpacelike/isEmbellished`, `Property notParent`, and `NodeValue core/coreMO`. `mml_node.cpp` still marks `AbstractMmlNode::isEmpty` as a Root stub; `mml_branches.cpp` marks token `isEmpty` and layout/base `coreMO` as stubs; `mml_nodes/mrow.cpp` marks row `isSpacelike`, `isEmbellished`, `core`, and `coreMO` as stubs; `mml_nodes/mstyle.cpp` marks `notParent` as a stub. The declarations are a useful shape but do not by themselves establish the callback/array iteration order above. The predicate corpus does not test token `isEmpty`, mutating callbacks during the three predicate loops, non-iterable child arrays, a successful `isSpacelike == true` row, or an `isEmbellished == true` row with exactly one embellished core and only spacelike siblings. In particular, none of its 25 `isEmbellished` values is true, so it supplies no successful result or core-index update evidence; Return32's separate getter-rebind fixture only establishes the specific original `[mo]` getter result and `_core = 0` used by that probe. The return corpus does not test mstyle whose first child has exactly one child (the true `notParent` result), or arbitrary child-slot accessor side effects. These remain uncovered source branches; do not infer them from the 75/32 observed rows.
