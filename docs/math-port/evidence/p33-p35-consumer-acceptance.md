# P33–P35 bounded MML consumer acceptance

Root accepts thirteen restored method bodies: mError and spacing dispatch;
five mrow/inferred-row methods, identifier class assignment and style child
inheritance; Math/HTML/prescripts/none verification. The three contracts and
agent implementation reports identify their owning upstream methods. No node
algorithm moved into a helper or combined feature router.

Root independently corrected the first parent reread in mError, the wrong-text
method error, and the native Missing check in Math verification before acceptance.
Root also corrected global math-class missing defaults: the original constructor
fails Object.create(undefined), while ordinary own missing defaults can be copied
as empty. The existing original constructor witness now passes. Null global static
defaults remain outside the current optional PropertyList metadata domain; this
packet makes no claim that that domain was expanded.
