# AMS/Newcommand native candidate

The independent Source observer is `tools/math-port/ams-newcommand-original-oracle.cjs`; it pins nine TypeScript files and their matching CJS outputs before executing the actual MathJax 4.1.3 classes. The generated Source corpus contains 24 complete input rows, two package configurations, nine static registrations, complete MML trees, dynamic-map entries, and ParseOptions `packageData`.

The native candidate is `tools/math-port/ams-newcommand-reference/ams-newcommand-native-candidate.cpp`. It initializes the actual parser runtime and Base/Newcommand/AMS modules, creates real TeX instances and MML factories, and calls the typed TeX compile path with a real native MathItem. Its tree serializer records kind, text, all attributes, all properties, and ordered children. The dynamic-map observer reads the actual protected `AbstractParseMap::map_` storage from a fixture-only derived observer; it neither copies nor populates a substitute map. Token and Macro entries are serialized from their native fields. The comparator in `tools/math-port/compare-ams-newcommand.cjs` strictly compares all 24 case rows and all four Source result fields (`result`, `error`, `dynamicMaps`, and `packageData`).

This candidate is not registered in the shared build yet and has not been compiled or run. The current package implementation is still under Root's compile gate. Therefore no AMS/Newcommand parity is claimed. Any unsupported native identity or serialization variant must fail the candidate explicitly rather than be emitted as a placeholder.
