# P27 table/script Native observer emitter repair

Implemented the Native C++ emitter/API adaptations in the three assigned oracle files. No fixture was generated and no check, build, test, or commit was run; Root owns independent generation and validation.

The C++ `children()` helpers now construct the established `ChildArray<MmlNode>` from `NodeValue` entries. The table probe's `getPrevClass` and sink `setTeXclass`, atom `Record::setTeXclass` and `Dispatch::adjustTeXclass`, and multiscript `Probe::appendChild` now use tagged `NodeValue` signatures and return values. Native result locals and identity comparisons use `NodeValue`, retaining Null versus Missing at the boundary. Null-slot mutations use `ChildArray::set(index, NodeValue(PropertyNull{}))`; indexed test setup reads use `get(index).requireNode()`.

Parent observations and writes in the emitted C++ now go through `getParent()`/`setParent()`. Chained source parent writes are emitted in their original right-to-left order. Native snapshot helpers implement the original `map` projection separately: capture the array handle and initial length, resize the result to preserve trailing holes, then perform live `has(index)`/`get(index)` and set only present output indices. A present nullish child projects to the callback's null result; a hole remains a hole. This does not replace the source methods' `for...of` or indexed live-length loops.

The pinned JavaScript source prefix preceding `const out=` was compared with `HEAD` and is byte-identical in all three oracle files. Source callbacks, case construction, assertion/raw-row counters, expected data, pins, and gold tables were left unchanged. Root's frozen profile counts remain: table 4,700 assertions/135 cases/240 inheritance rows/160 rule rows/428 values; atom-semantics 6,888/74/924/157; multiscript 1,304/226/480/1,170.

Root's independent compile gate found one remaining legacy ChildArray expression in the atom-semantics outer-parent observer: its C++ assertion indexed `cs` with `[]` and compared the logical `Parent()` result directly to a raw pointer. The emitter now gets the node through `cs->get(i).requireNode("Parent")` and compares the returned tagged `NodeValue` against `NodeValue(holder)` or `NodeValue(n)`. This keeps the source observer's logical-parent check. Root owns regeneration and recompilation; neither was run here.

Method/API mapping: `table-oracle.cjs` emits ChildArray/NodeValue setup, `parentValue`/`childrenSnapshot`, typed TeX-class dispatch, and the table null-slot write; `atom-semantics-oracle.cjs` emits typed TeXAtom/Mo adjustment and child dispatch plus map-style snapshot and parent projection; `multiscript-oracle.cjs` emits typed append dispatch, ChildArray indexed read/write, parent setup, and map-style snapshots. The actual source traversal algorithms and source-side projections were not changed. This report records implementation scope only and is not Root acceptance.
