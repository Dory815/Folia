# P30 options representation acceptance

Root replaced the verification/error parameter domain with the existing
Property value across all twenty affected production files. ErrorOptions and
the Html/multiscript nullable conversion helpers are removed. There is no second
options path or compatibility overload. Algorithm stubs remain honest stubs;
the local Source default evaluation is assigned separately in P32 and later
subclass method packets.

Root repaired six Native emitter templates and regenerated their six fixtures.
All original JS stimuli, generated expected assertions and Source value graphs
remain unchanged. C++ empty-object/null argument spellings were made explicit
where needed. The before/after comparison checks 9,037 expected/value lines,
normalizing only those precisely allowed Native stimulus spellings. All seven
original emitters (including unchanged leaf) reproduce their fixtures with the
same case/assertion/value counts recorded in the contract. This does not make
their unaccepted algorithm runtime tests pass.

The normal repository core builds and links. Root's typed domain test executes
476 assertions over twelve actual class families: all four virtual slots for
the ten ordinary-node families, both public slots for Empty/Text and Html. It
preserves raw undefined/null/scalars, NaN/signed-zero bits, array/object identity,
retained object mutation and Missing call-site defaults through base and derived
static pointer types. The typed observers override methods to inspect dispatch;
they do not claim those Source implementation defaults are already ported.

Focused normal-core regressions pass: replacement 1,508 assertions/two tests,
template inheritance 9,344/one, token walk 784/two, Attributes 445/one executed
test (two other registered tests filtered), and inherited closure 929/five.
The unchanged primitive oracle reproduces 1,223 checks. No full-core runtime
pass is claimed; base/subclass verification/error construction and many other
math methods still remain unaccepted.

Initial build repairs included missed explicit-null emitter stimuli, an
unspaced parameter token, a helper's obsolete Property.get call and an
accidentally changed object-construction spelling. Root fixed the emitters,
not expected values. The new boundary observer also needed explicit imports,
the correct Empty/Html public-only hierarchy and an actual registered kind for
its abstract-node fixture. Failed builds/observer construction were not counted
as passed assertions. Final checks described above pass.
