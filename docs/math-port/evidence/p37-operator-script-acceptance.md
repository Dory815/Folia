# P37 operator, TeXAtom and under/over acceptance

Root accepts thirteen restored semantic methods under the frozen ownership
contract: five Mo class/core methods, getForms, two pseudo/accent methods, two
under/over inheritance methods, two TeXAtom methods and one shared adjustment
algorithm. Mo and TeXAtom directly delegate to that single Source algorithm.
Parsing, layout, fonts and output remain outside these classes.

The real preimplementation red gate is recorded in bba12bf. It compiles the actual
90-module graph and exits 1 through Unimplemented bodies with byte guards passing.
Rejected implementation attempts exposed raw accent normalization, Source public
constructor setter bypass and three exact null-array iteration error differences.
Root corrected these responsible boundaries without changing existing gold.
Constructor prevClass/prevLevel now dispatch public virtual setters in Source
declaration order before protected texclass initialization. Iterative core/parent
walks consume the existing Native TreeCallGuard resource budget; this is explicitly
a Native termination rule, not a JavaScript stack-capacity equivalence claim.

## Final verification

The final tools/math-port/mml-operator-script-gate.cjs baseline passes 32828
assertions in 162 executed tests. All 33 independent semantic faults compile
and then fail assertions with exit 1. Final production and fixture byte guards
pass. Coverage includes every restored semantic method, shared adjustment used
by both classes, raw accent identity, explicit null, spacing/fence classes,
forms, pseudo spacing, iterator bounds, the original over-branch under-core
behavior, raw prime, movable limits, accent rereads and default comparison.

The normal build_test.bat target builds and links all fixtures. Affected filters
pass: generic constructor 91/2; verification 4232/3; original MML-node 1084/43;
atom 6888/74; script 1689/18; operator 13598/11; math accent 33/1; raw accent 72/1;
forms boundary 9/1. The Mo-name filter also passes its 1136/16 matching checks.
Test output is retained under ignored build/p37-normal-* logs. Isolated matrix
results are in ignored build/math-port-operator-script-consumers/results.json.

Native capability types model Source text/token/row/indexed-child operations;
they do not claim arbitrary JavaScript duck typing or named-property reflection.
These bounded methods do not accept the full original-source scope or a working
renderer. Remaining action/MathChoice/layout-node consumers, complete TeXParser,
packages, common layout, fonts, SVG and Folia integration remain required.
Folia still uses its existing QuickJS math path. Mermaid remains paused.
