## Public inputs and prerequisite constructor outcomes

`Paint<'a>` exposes `shader: Shader<'a>`, 29-value raster `blend_mode`, `anti_alias`, four-value `colorspace`, and `force_hq_pipeline` (`painter.rs:31–75`). `Default` is solid black, SourceOver, AA enabled, Linear and no forced HQ (`77–86`); `set_color`, `set_color_rgba8` and `is_solid_color` are at `89–105`. This is the original raster Paint. The accepted native `scene/prepare/blend_policy_types.rs::RasterBlendMode` is its policy type; `scene/paint.rs` has a distinct 16-value CSS blend enum and cannot supply the 29-way constructor input. `PixmapPaint` (`shaders/pattern.rs:28–59`) is the public image-drawing convenience struct, **not** the `Paint` passed to `RasterPipelineBlitter::new`.

Original `Shader<'a>` has SolidColor, LinearGradient, RadialGradient, SweepGradient and Pattern (`shaders/mod.rs:41–61`). Relevant public construction paths are:

| --- | --- | --- |
| SolidColor | `Shader::SolidColor(Color)`; `Color::from_rgba`/`from_rgba8`, or `Paint::set_color`/`set_color_rgba8` | Color validation precedes direct variant construction. SolidColor is the only `Paint::is_solid_color()` variant (`painter.rs:103–105`). |
| Linear | `LinearGradient::new(start:Point,end:Point,stops:Vec<GradientStop>,SpreadMode,Transform)->Option<Shader<'static>>` (`linear_gradient.rs:35–41`) | Empty/nonfinite geometry/noninvertible transform may reject; one stop or near-degenerate geometry can return SolidColor instead (`42–87`). |

`GradientStop::new(position,Color)` clamps its normalized position (`gradient.rs:23–37`). `Shader::is_opaque` considers radial and Pattern **false**, regardless of their apparent pixels, and dispatches other variants (`shaders/mod.rs:63–75`). `transform`, `apply_opacity` and `push_stages` are original methods at `95–145` and `79–93`. If the observer applies public transforms/opacities, it must do so to the same Shader **before** calling the blitter; constructor snapshot should separately record requested factory kind and actual returned variant. Existing Root `shader-public-observer.cjs` already describes public factory/variant state; it can be reused as an input recipe, not used as native-derived expected data.

## Exact `new` and `new_mask` control order

1. `RasterPipelineBlitter::new(paint:&Paint<'a>,mask:Option<SubMaskRef<'a>>,pixmap:&'a mut SubPixmapMut<'b>)->Option<Self>` first compares mask and target **logical** width/height. If unequal, it logs `Pixmap and Mask are expected to have the same size` and returns `None`, even if the blend would later fast-reject (`pipeline/blitter.rs:31–44`). Mask parent stride is not compared with target parent stride.
2. Fast rejection: Destination returns `None`; DestinationIn returns `None` only when `paint.shader.is_opaque() && paint.is_solid_color()` (`46–55`). Opaque SourceOver becomes Source only with `mask.is_none()` (`57–61`). A solid Source with no mask caches the **unexpanded** solid color's `premultiply().to_color_u8()` as `memset2d_color`; it does not run the selected ColorSpace expansion to obtain the cached byte (`63–71`). Clear with AA disabled and no mask changes to Source and caches transparent bytes, irrespective of shader (`73–77`). These choices occur before the first shader producer call.
3. Anti-h builder is new/default, takes `force_hq_pipeline`, calls `shader.push_stages(colorspace,&mut builder)` once, and returns `None` immediately on false (`79–84`). Optional mask appends MaskU8. Coverage pre-scale chooses Scale1Float before destination load, else Lerp1Float after blend; destination gamma expansion and output compression are conditional selectors; Store closes the program. It compiles at `116` (`86–117`).
4. Rect builder is a **second** new/default builder/context, again sets force and calls the same shader producer once (`119–124`). Optional MaskU8 follows. Only exact SourceOver with `mask.is_none()` takes the compressed SourceOverRgba fused path (`130–135`). Otherwise Source skips destination load; other modes load destination, then only if `to_stage()` is Some append destination gamma expansion followed by blend. Compression and Store follow (`137–153`). The order `to_stage` before `expand_dest_stage` in this branch is observable in the original selector call sequence, even though both are pure selectors.
5. Mask builder is a **third** new/default builder/context, sets force, calls shader producer once and may return `None` (`156–161`). Optional MaskU8 follows. Its coverage branches parallel anti-h but use ScaleU8/LerpU8, then conditional compression and Store (`163–194`). A capacity panic during any push/compile remains a panic, not `None` or truncation. Only after all three compile does the constructor select Pattern's borrowed `PixmapRef` or the valid 1×1 transparent dummy, then store fields and return Some (`196–212`). For Pattern inversion failure, the **first** producer call warns `failed to invert a pattern transform. Nothing will be rendered` and returns false (`shaders/pattern.rs:97–104`); no later builders are created.
6. `new_mask(pixmap:&mut SubPixmapMut)->Option<Self>` has no Paint, optional logical mask, blend or shader constructor input. It takes premultiplied white, caches white bytes, and constructs three **separate** default-force white-uniform builders: anti-h adds LoadDestinationU8→Lerp1Float→StoreU8, rect adds StoreU8, mask adds LoadDestinationU8→LerpU8→StoreU8 (`pipeline/blitter.rs:214–242`). It stores mask None, dummy 1×1 source, `is_mask=true`, and returns Some (`244–254`). It targets A8 storage represented by the same raw `SubPixmapMut` shape.

The accepted Native `PipelineBuilder` already has a 32-entry single stage list, one context, force flag and consuming `compile`; accepted `PreparedShader::push_stages` consumes a passed builder but owns no duplicate context (`scene/prepare/pipeline_builder.rs`, `prepared_shader_types.rs`, `shader_dispatch.rs`). The accepted `LogicalTarget` and `LogicalMaskRef` expose logical `IntSize`, real parent widths and post-offset borrowed slices (`scene/prepare/blitter/surface_types.rs`). Native low-level `DestinationSurface`/`MaskSurface` are execution views with no logical dimensions; they should not replace the constructor arguments. Native Pattern `SourcePixmap` borrows the original image bytes and must outlive all three producer calls and eventual blitter runs. The future blitter value must own **three distinct** `CompiledPipeline<PipelineContext>` values, never three clones of one produced context.

## Minimal append-only actual-Source snapshot seam

At original `pipeline/blitter.rs`, add a read-only observer beside the private `RasterPipelineBlitter` fields, after invoking the unchanged `new`/`new_mask`. For Some, project: `is_mask`, optional-mask presence and logical size/real width, target logical size/real width/borrowed slice offset and length, `pixmap_src` size/byte length and Pattern-image pointer identity (for non-Pattern verify 1×1 transparent content rather than a process-specific dummy pointer), optional `memset2d_color` RGBA bytes, and **three named** compiled pipeline snapshots in anti-h/rect/mask order. For None, capture constructor outcome and warning; do not synthesize partial compiled programs that Source does not return. Wrap the original call to distinguish panic, `None` and `Some`; preserve warning multiplicity and order.

The Source `RasterPipeline.kind` is private to `pipeline/mod.rs` (`485–499`), so append a read-only helper there that projects each actual compiled pipeline's precision, 8/16 width, full and tail function IDs including Return, and the complete 15-group `Context` f32-bit snapshot. Root's existing `shader-run-observer.cjs` already defines `folia_shader_function_id` for both precision tables, tail substitutions and Return, plus `folia_shader_context` from the existing pattern producer projection. Reuse **those** actual-function-pointer and context readers for each of the three compiled values; do not reconstruct expected stages from blend formulas, copy one shader-run into three records, call `push_stages` a fourth time, or reset context to a single canonical value. `RasterPipelineBuilder::compile` moves its own context into the compiled value (`pipeline/mod.rs:395–482`), which the snapshot should read unchanged. If a later execution witness is added, it should run each stored pipeline through unchanged `RasterPipeline::run` and compare that pipeline's own before/after context plus complete destination bytes.

The fixture should control public factory input and actual returned variant, all 29 raster BlendModes, all four ColorSpaces, all five Shader families, `anti_alias`, `force_hq_pipeline`, opaque/translucent colors and stops, mask None/Some, and both full-target and intersected subtarget/submask. A core 29×4×5 matrix with valid representative constructors makes every policy product observable, with separate edge rows for factory None/panic, mask mismatch before Destination, DestinationIn opaque-solid rejection versus opaque non-solid/always-false radial/Pattern, opaque SourceOver reduction with and without mask, Source/solid cached premultiplied byte thresholds, Clear AA/mask quadrants, Pattern inverse failure warning, capacity panic, and all three independent compiled contexts. Include Pattern nearest/bilinear/bicubic, source image dimensions/extra bytes, nonzero subregion offsets, equal logical mask/target size with unequal parent strides, and new_mask A8 targets. The observer must build a fresh original Paint/Shader and borrowed surfaces for each case; never derive original records from Native output or use generated gold as constructor state.
