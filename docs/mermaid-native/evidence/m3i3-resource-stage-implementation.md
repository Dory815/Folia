# M3i3a resource-stage implementation ledger

Status: Sol implementation delivered to Root for independent Source review, build, corpus, mutation and matrix checks. This is **not** acceptance of the stages, a complete pixel pipeline, or the Mermaid backend. Only `sampling/resources/highp.rs`, `sampling/resources/lowp.rs`, and this report were edited.

The fixed sources are pristine tiny-skia 0.12.0 `src/pipeline/highp.rs` SHA-256 `81388733345dbae3d29cbf758831809847bb1aa30a13f600d0672409bce38416`, `lowp.rs` `3cc2fe168ae06273ff16bbc972b337e064b24c028a089e47aa14f5eb48752e88`, and `mod.rs` `fbbe3f276b7e95fdf501fe0420f60d18ca313395cdf79aa1a943e9ef996243a4`. Pinned execution profile is `std+simd` x64 MSVC. Both implementations use the Root-owned original wide vector provider; byte unpack/pack loops mirror Source's per-pixel conversion and preserve the native borrowed destination/mask lifetimes.

Raw RGBA storage is treated in original `PremultipliedColorU8` byte order RGBA (`color.rs:95–149`); no `Pixmap` validation or allocation is introduced. Valid cursor, stride, storage length and AA shift remain producer obligations from the frozen contract. Both files retain separate `ResourceProgram::Full`/`Tail` read/write counts rather than selecting a family from `cursor.tail`. A mask Stop applies only to one invocation; later chunks/rows belong to the caller. This packet does not implement blend ordinals 18–44, image-pattern gather/filter, full three-path blitter assembly, Source render pixels, D2D, SVG, or Folia. Per delegation, I did not run builds or tests and did not inspect expected fixture values.
