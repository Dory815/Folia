## `Gradient::push_stages`: complete wrapper order

`Gradient::push_stages(&self,p,cs,pre,post) -> bool` (`gradient.rs:106–258`) wraps the M3f radial stage sequence. Every branch is relevant:

1. Append `SeedShader` **before** trying `self.transform.invert()` (`:113–121`). Failed inversion warns and returns `false`; `Shader::push_stages` callers interpret false as no draw, not fallback shader (`shaders/mod.rs:79–92`, `pipeline/blitter.rs:79–84,119–124,156–161`). The builder contains the SeedShader stage at that intermediate point, but the blitter discards the failed program. On success compute `ts = inverse_transform.post_concat(points_to_unit)`, then `RasterPipelineBuilder::push_transform(ts)` (`gradient.rs:122–123`, `pipeline/mod.rs:370–375`). That helper appends `Transform` and stores context only for **finite non-identity** `ts`; it does not return failure for nonfinite `ts`. M3e supplies `points_to_unit`; the separate shader transform is still needed.
2. Call `pre(p)` (`:125`): for radial this is exactly M3f `before_color` (`radial_gradient.rs:259–304`). It follows seed/optional transform and precedes spread/color. Source initializes radial `p0/p1` and a zero validity mask before entering the wrapper (`radial_gradient.rs:234–259`).
3. Spread (`gradient.rs:127–143`): Reflect appends `ReflectX1`; Repeat appends `RepeatX1`; Pad appends `PadX1` **only if `has_uniform_stops`**, otherwise appends nothing so hard stops at 0 or 1 survive general search. `highp.rs:894–914` / `lowp.rs:573–600` implement pad by `normalize(t)`, reflect by `abs((t-1)-2*floor((t-1)*0.5)-1).normalize()`, repeat by `(t-floor(t)).normalize()`. `wide/f32x8_t.rs:63–65` defines normalize as max with zero then min with one. Do not substitute a D2D spread enumeration before choosing this Source branch.
4. Two normalized stops (`gradient.rs:145–162`): assert uniform, expand both `Color`s with `cs.expand_color`, create `EvenlySpaced2StopGradientCtx.factor = c1-c0` per RGBA channel and `bias=c0`, then append its stage. `ColorSpace` defaults to Linear but has Gamma2, SimpleSRGB and FullSRGBGamma expansion for RGB while alpha remains unchanged (`color.rs:455–501`). No integer-byte quantization happens in this context.
5. More than two normalized stops (`gradient.rs:163–250`): create `GradientCtx` with actual `len`, `factors`, `biases`, `t_values` (`pipeline/mod.rs:281–331`), reserving `max(stops.len()+1,16)` for factors/biases. Choose `first_stop=0` if first two colors differ else `1`; choose `last_stop=len-1` if final two colors differ else `len-2`, thereby dropping endpoint dummy colors only when equal (`:179–197`). Seed an initial constant color and t-value zero (`:199–202`); for each `i in first_stop..last_stop`, update right t/color, emit `F=(c_r-c_l)/(t_r-t_l)` and `B=c_l-F*t_l` plus t-value `t_l` **only when `t_l<t_r`**; then advance both left values even for equal positions (`:203–231`). Emit final constant color/t-value, set `ctx.len=factors.len`, assert vector lengths match, pad factors/biases with zero entries to at least 16, append `Gradient`, and store the context (`:233–250`). `GradientColor` is unpremultiplied f32 and is explicitly allowed outside `[0,1]` (`pipeline/mod.rs:281–305`); premature native RGBA clamping changes hard-stop/interpolation behavior.
6. Append `Premultiply` iff `!colors_are_opaque` (`gradient.rs:252–254`), then call `post(p)` (`:256`); for radial, M3f `after_color` is the Strip/non-well-behaved Focal `ApplyVectorMask` and must follow optional premultiplication (`radial_gradient.rs:305–311`). Return `true` (`gradient.rs:258`). Source radial's conservative `Shader::is_opaque=false` is a separate blending optimization decision, not the `Premultiply` flag.

`RasterPipelineBuilder::compile` checks **all** appended stages against the lowp function table and `force_hq_pipeline`; a single `null_fn` forces the whole highp program (`pipeline/mod.rs:395–480`). The M3f `geometry_lowp_compatible` flag only covers M3f stages. Even ordinary Radial can become highp through non-linear destination color-space stages or blend stages (`lowp.rs:71–154`; `pipeline/blitter.rs:79–194`). A typed wrapper observer can compare the exact whole emitted stage sequence, optional transform context, both color contexts, and returned bool without running a pixel backend.

## Sampling responsibility after preparation

The Source pipeline stage enum is `pipeline/mod.rs:68–150`; runtime context holds pixel transform, radial `p0/p1/mask`, two-stop factor/bias or general stop vectors (`:252–339`). A prepared stage list **does not execute** these kernels:

| Sampling group | Actual Source behavior / sites |
| --- | --- |
| Seed and transform | Highp seeds eight f32 pixel centers `(dx+0.5,dy+0.5)` and zeroes destination registers (`highp.rs:256–269`); lowp seeds 16 centers in two f32x8 halves (`lowp.rs:255–266`). Both transform coordinates using nested `mad(x,sx,mad(y,kx,tx))` and analogous y; Source `mad` is `f*m+a`, with its operation order (`highp.rs:693–702,1357–1359`; `lowp.rs:558–571,899–902`). |
| Radial and concentric | `XYToRadius = sqrt(x*x+y*y)` (`highp.rs:1020–1026`, `lowp.rs:649–657`); concentric bias is separate `t=t*p0+p1` (`highp.rs:1129–1137`). Only plain radius exists in lowp; bias is lowp `null_fn` (`lowp.rs:132–144`). |
| Strip | `t=x+sqrt(p0-y*y)` then mask **NaN t only**, replacing invalid t with zero and saving validity (`highp.rs:1066–1085`). Negative non-NaN t remains valid for subsequent spread/search. Lowp lacks both stages (`lowp.rs:137–140`). |
| Focal | On-circle `x+y*y/x`; well-behaved `sqrt(x*x+y*y)-x*p0`; greater `sqrt(x*x-y*y)-x*p0`; smaller `-sqrt(x*x-y*y)-x*p0` (`highp.rs:1028–1064`). Non-well-behaved masks `t<=0` **or NaN**, then optional `NegateX`, `t+=p1`, `t=1-t` in M3f order (`:1087–1096,1109–1127`). All are highp-only (`lowp.rs:133–144`). |
| Stop lookup | Highp general search counts `t >= t_values[i]` for `i=1..ctx.len` then evaluates per-channel `mad(t,F[idx],B[idx])`; two-stop stage directly evaluates its factor/bias (`highp.rs:916–989`). Lowp performs the same f32 t search in 16 lanes, then rounds/clamps RGB and scales to byte-valued u16 lanes via `round_f32_to_u16` (`lowp.rs:602–730`). Signed-zero/equal-stop and out-of-range t therefore matter. |
| Opacity and validity | Highp optional premultiply does f32 RGB `*=alpha` (`highp.rs:211–217`); lowp first rounds channels and then uses integer `div255(rgb*alpha)` (`lowp.rs:237–243,849–854`). Strip/Focal post-stage bitwise-ANDs all RGBA float lanes with saved mask **after** interpolation/premultiply (`highp.rs:1098–1107`). Setting invalid t to zero without that final mask would show the first stop. The builder's later coverage/blend/store stages are separate (`pipeline/blitter.rs:79–194`). |

Sampling is a consumer responsibility, not part of a pure stop or stage-plan preparation API. Stage order, mask timing, color-space conversion and whole-pipeline precision must be retained in a later native pixel comparison. D2D brush behavior cannot be presumed equivalent to these Source operations.

## Smallest complete next packet and suggested order (not frozen)

**Candidate first packet: complete Source stop preparation.** Include `GradientStop::new`, `Gradient::new` and `Gradient::apply_opacity` as one coherent f32 responsibility, with normalized ordered stops, tile mode and both transforms retained and `colors_are_opaque`/`has_uniform_stops` observable. This is the smallest packet that supplies every input branch needed by the wrapper without taking on sampling. Do not implement only dummy insertion or a two-stop shortcut. Root can append read-only observers to a pristine Source copy to expose private final stops/flags/transforms, construct actual Source `Color`/`GradientStop`, call the original methods, and compare native bits for finite/signed-zero values and NaNs by category. Include raw f32 offset boundaries, `strict-num` nonfinite-to-zero, duplicate/hard stops, first/last missing, descending positions, opacity and threshold neighbors, plus the M3e thin-ring replacement ordering. This proposal makes no native API choice.

**Candidate second packet: complete `Gradient::push_stages` wrapper and color contexts.** Freeze a typed representation for SeedShader, optional transform, radial pre/post slots, spread stage, two-stop or general context, optional premultiply, and `false` return. Compare actual Source stage sequence, context values and return with a Source observer executing unchanged `Gradient::push_stages` (or actual radial caller) over the accepted M3e/M3f values and independently varied stops, tile modes, transforms, opacity and ColorSpace. Preserve f32 factors/biases and dummy/hard-stop rules. The prior M3f fixture intentionally used an identity two-stop wrapper and cannot accept this packet by itself.

**Later packet: complete sampled paint.** Port or reproduce each required highp/lowp stage's runtime effect, final precision selection, mask and postpass in both consumers; verify independent actual Source sample/pixel observations at multiple positions, image sizes, DPI, colorspaces, spread/stop forms and blending contexts. Only after a typed radial resource, shared scene validation, SVG export and D2D consumption exist can root assess backend parity. No present assertion that a native D2D radial brush matches Source is supported by the files above.
