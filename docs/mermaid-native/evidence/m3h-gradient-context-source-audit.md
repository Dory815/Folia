## `ColorSpace::expand_color` and every direct numeric helper

`ColorSpace` is four-valued, with `Linear` as default (`color.rs:455–477`). `expand_color(mut color)` assigns `r`, then `g`, then `b` by calling `expand_channel` separately, and leaves alpha unchanged (`:497–502`). Its input is Source `Color`, whose channels are `NormalizedF32`; M3g `StopColor::from_rgba` likewise rejects invalid/nonfinite channel construction. Thus a safely constructed color cannot feed NaN or infinity into `expand_channel`; raw invalid channel rejection is an M3g boundary, not a new ColorSpace policy. Signed zero and finite subnormal values remain possible through `NormalizedF32::new` (`strict-num:483–489`).

| Mode | Exact Source channel operation (`color.rs:479–495`) | Direct helper/threshold |
| --- | --- | --- |
| `Linear` | Return the input `NormalizedF32` unchanged. | No clamp or arithmetic. |
| `Gamma2` | `x * x` on `NormalizedF32`. | `strict-num:552–559` multiplies the two underlying f32 values, then calls `NormalizedF32::new_clamped` on the product. |
| `SimpleSRGB` | `NormalizedF32::new_clamped(approx_powf(x.get(), 2.2))`. | Literal exponent is f32 in the function call. The helper is Source's approximation, not `f32::powf` (`math.rs:27–56`). |
| `FullSRGBGamma` | Convert to f32; if `x <= 0.04045`, use `x / 12.92`; otherwise use `approx_powf((x + 0.055) / 1.055, 2.4)`; wrap the result in `NormalizedF32::new_clamped`. | Inclusive threshold and the add/divide/power order are explicit; alpha is never gamma-expanded. |

`approx_powf` first returns `x` verbatim for `x == 0.0 || x == 1.0`, including a possible signed-zero input (`math.rs:28–31`). Otherwise it converts `x.to_bits()` to f32 to form `e`, constructs `m` from masked bit fields, computes `log2_x = e - 124.225514990 - 1.498030302*m - 1.725879990/(0.3520887068+m)`, then `x=log2_x*y`, `f=x-floor(x)`, and updates `a` through `+121.274057500`, `-=f*1.490129070`, `+=27.728023300/(4.84252568-f)`, `*=(1<<23) as f32` in that order (`:33–45`). It returns `f32::from_bits(a.round() as u32)` when `a` is below the infinity-bit threshold and positive, zero when that finite branch is nonpositive, otherwise infinity (`:47–55`). Any nonfinite result subsequently passed to `NormalizedF32::new_clamped` becomes zero (`strict-num:503–513`); `clamp_f32` for finite results is `max.min(val).max(min)` (`:670–673`). A NaN result from this helper fails `a < infinity_bits` and reaches its infinity return, then the normalized clamp maps it to zero. This describes Source control flow, not a proposed invalid-color acceptance rule.

The FullSRGBGamma cutoff `<= 0.04045` is separate from M3g's inclusive `Scalar::is_nearly_equal` tolerance `1/4096` used for `has_uniform_stops` (`gradient.rs:78–94`; `scalar.rs:12,56–70`). These comparisons must not be conflated. `ColorSpace::expand_stage`, `expand_dest_stage` and `compress_stage` (`color.rs:522–545`) are distinct selectors used later by the blitter; they are not called by `expand_color` or `Gradient::push_stages`. Their presence can affect final highp/lowp compilation once blending is appended, but color context construction itself adds no gamma stage.

## Context types and all `Gradient::push_stages` assignments

`pipeline/mod.rs:281–339` declares `GradientColor {r,g,b,a:f32}` as **unpremultiplied and potentially outside `[0,1]`**. `GradientColor::new` copies each f32; `From<Color>` copies getter values in r/g/b/a order (`:291–306`, getter sites `color.rs:264–289`). `EvenlySpaced2StopGradientCtx` has `factor` and `bias` (`pipeline/mod.rs:308–312`). `GradientCtx` has `len:usize`, `factors:Vec<GradientColor>`, `biases:Vec<GradientColor>`, and `t_values:Vec<NormalizedF32>`; `push_const_color` appends zero factor and the supplied color bias (`:314–331`). `TwoPointConicalGradientCtx {mask,p0,p1}` is separately initialized by radial `push_stages` **before** the generic wrapper (`radial_gradient.rs:234–259`; `pipeline/mod.rs:333–339`).

The wrapper signature is `Gradient::push_stages(&self, p:&mut RasterPipelineBuilder, cs:ColorSpace, push_stages_pre:&dyn Fn(...), push_stages_post:&dyn Fn(...)) -> bool` (`gradient.rs:106–112`). Exact phase sequence:

1. Append `SeedShader` (`:113`). Attempt `self.transform.invert()`; failure warns/returns false after that append, with no color context computation (`:115–121`). Success computes `inverse.post_concat(self.points_to_unit)` then asks `RasterPipelineBuilder::push_transform` to append `Transform` and store `ctx.transform` **only if finite and non-identity** (`:122–123`; `pipeline/mod.rs:370–375`). The wrapper does not validate the composed transform separately or return false when `push_transform` omits it.
2. Call `push_stages_pre` (`:125`), which for radial is M3f `before_color`. M3f supplies ordered radial stage codes and `p0/p1`, while runtime mask starts zero in Source (`radial_gradient.rs:253–304`).
3. Append `ReflectX1` for Reflect, `RepeatX1` for Repeat, `PadX1` for Pad **only when** M3g `has_uniform_stops` is true; otherwise no Pad stage (`gradient.rs:127–143`). The absent Pad stage is essential to hard-stop search. This selection uses M3g-prepared spread/uniform metadata verbatim.
4. **Exactly two prepared stops**: expand `c0`, then `c1` using the selected ColorSpace; assign `p.ctx.evenly_spaced_2_stop_gradient.factor` to channelwise `c1-c0` in r/g/b/a order and `bias` to `GradientColor::from(c0)`; append `EvenlySpaced2StopGradient` (`gradient.rs:145–162`). This path tests stop **count**, not merely uniformity; `debug_assert!(has_uniform_stops)` is an assertion, not a fallback. The other gradient context stays at its builder default unless modified elsewhere.
5. **More than two prepared stops**: construct default `GradientCtx`; reserve `max(stops.len()+1,16)` factor/bias capacity and `stops.len()+1` t-value capacity (`:163–177`). Determine `first_stop` from equality of first two **Source Color values** (`0` when unequal, otherwise `1`), `last_stop` from equality of last two (`len-1` when unequal, otherwise `len-2`); no offset-based deduplication (`:179–197`). Initialize `t_l`/expanded `c_l` from first, append constant color with t-value `NormalizedF32::ZERO` (`:199–202`). For each index in `first_stop..last_stop`, obtain `t_r` and expanded `c_r`; if `t_l<t_r`, append `F=(c_r-c_l)/(t_r-t_l)` for each channel, then `B=c_l-F*t_l`, then normalized `t_l` (`:203–227`). Regardless of equality, update `t_l=t_r` and `c_l=c_r` (`:229–230`), so coincident hard stops affect the following interval. Append final constant color and normalized `t_l`; assign `ctx.len=ctx.factors.len()` before padding; debug-assert lengths; append zero factors/biases until at least 16 (not `t_values`); append `Gradient`, then assign `p.ctx.gradient=ctx` (`:233–250`). In Source `GradientColor::default` is four positive f32 zeros (`pipeline/mod.rs:283–289`). The two-stop context remains builder default on this branch.
6. Append `Premultiply` if M3g `colors_are_opaque` is false; call post closure; return true (`gradient.rs:252–258`). For radial the post closure places `ApplyVectorMask` after optional premultiplication (`radial_gradient.rs:305–311`). The wrapper does not calculate sample `t`, choose vector precision, or apply that mask.

The general context can contain factors or biases outside normalized color range, including nonfinite results from division by very small but distinct f32 t-values; the Source does not clamp `GradientColor` (`pipeline/mod.rs:281–305`, `gradient.rs:208–226`). Stage sequence and context need to preserve f32 order; f64 intermediates, byte colors, D2D stop interpolation, merging equal-position stops, or clamping factors/biases would change the observed data. Highp general lookup counts `t >= t_values[i]` then applies `mad(t,F[idx],B[idx])`, and two-stop lookup also applies per-channel `mad` (`highp.rs:916–989`); lowp uses the same context but rounds channels to byte-valued u16 later (`lowp.rs:602–730`). These are later sampling responsibilities, not context construction.

## Existing inputs and Source observation seam

The currently accepted `third_party/mermaid-rs-renderer/src/scene/prepare/gradient_stop_types.rs` (SHA-256 `6a47a592c404010fe11ec1cc297ca41faa434df906962a87d26fdc6c247da95d`) has one normalized f32 stop vector, spread, shader transform, points-to-unit transform, opaque flag and uniform flag. `gradient_stops.rs` (SHA-256 `5bb6efdd694109e088010360213edb371463cb282a3a6da8b768bb190b76f9a0`) exposes read-only `StopColor::components`, stop `position/color` and all prepared-gradient metadata. M3f's `radial_stage_types.rs` (SHA-256 `ad41eff572164bf5cea863d1be15ad8fff8d26dc5edfbf3bd1b466ba05e38551`) provides `p0/p1`, ordered `before_color`/`after_color` and radial-stage-only lowp eligibility; `radial_stages.rs` (SHA-256 `16b6e15fa0a4ffdf8f0bd41e6f5d2720bef65ee57927017a0372fc3d70bb7f37`) computes it. No accepted type yet carries ColorSpace, optional effective transform, generic spread/color stage identifiers, two-stop factor/bias or general factor/bias/t-value arrays, wrapper success/failure, or whole-pipeline precision. The existing scene paint resource remains linear-only; this audit does not choose a new representation.

For root's interface freeze, the **minimal observational state** of a complete wrapper is: input M3g prepared stops/flags/spread/transforms; selected Source ColorSpace; M3f radial `p0/p1` and pre/post sequence; returned bool; ordered emitted stage sequence `[SeedShader, Transform? , radial pre..., spread? , EvenlySpaced2StopGradient|Gradient, Premultiply? , radial post...]` on success (and the partial SeedShader prefix on inverse failure); conditional `ctx.transform`; active factor/bias context or `GradientCtx {len,factors,biases,t_values}` including padding; and radial context `p0/p1` plus initial mask. This is an inventory of Source-observable values, **not** a proposed native struct/API. Whole-pipeline lowp/highp additionally depends on every appended blend/colorspace stage and `force_hq_pipeline` (`pipeline/mod.rs:395–480`, `lowp.rs:71–154`), beyond M3f eligibility.

An independent Source oracle can append read-only observers to a pristine copy and execute actual `ColorSpace::expand_channel/expand_color`, `GradientColor::from`, and actual `Gradient::push_stages` with actual M3g-equivalent Source stops and actual radial pre/post closures. It can observe color channel bit patterns; branch choice; returned bool; stage order; `ctx.transform`; `ctx.evenly_spaced_2_stop_gradient`; `ctx.gradient.len`, every factor/bias and t-value including padding; and radial context. Input families should include all four ColorSpace modes, zero/one/subnormal/signed-zero channels, FullSRGBGamma threshold and adjacent f32 values, two vs three or more stops, endpoint dummy colors, equal-position hard stops, descending normalized inputs, near-equal uniform steps, repeated opacity, singular/nonfinite/identity/composed transforms, all spreads, and M3f Radial/Strip/Focal pre/post sequences. The values and expected bits must come solely from execution of unchanged Source bodies; no agent-produced formula table should be used as the fixture. Root owns observer design, cases, frozen API, tests, mutations and acceptance.
