# Folia 0.2.1

Folia (折笺) is a native Windows Markdown reader and editor built with WinUI 3,
Direct2D, DirectWrite, and C++23. This maintenance release improves scrolling
responsiveness, high-refresh-rate interaction, and nested Markdown layout while
preserving Folia's source-faithful editing model.

## Highlights

- Fixed a frame-pacing precision issue that could flood the UI thread with
  drawing callbacks and cause scrolling stalls on systems with long-running
  clocks.
- Scrollbar dragging now shares the display-aware frame scheduler used by
  wheel scrolling. Dragging follows the latest position without added inertia,
  submits the final position on release, and stops scheduling when finished.
- Preserved gradual mouse-wheel deceleration while removing the scheduling
  stalls that previously delayed input.
- Corrected list continuation and indented-code parsing to respect list content
  columns and tab stops, including display-math blocks nested in list items.
- Fixed vertical spacing around nested code and math blocks so adjacent text
  and code backgrounds no longer overlap.
- Reused complete SVG vector drawing records during rendering, with bounded
  cache retention and invalidation for source, viewport, DPI, and device changes.
- Added deterministic regression coverage for indentation, block spacing,
  SVG rendering, scroll response, and frame pacing across refresh rates and
  clock uptimes.
- Updated application and installer metadata for the `0.2.1` release.

## Installation

Download `Folia-0.2.1-x64.msi` from the assets below and run it for a per-user
installation. Folia supports 64-bit Windows 10 and Windows 11. The installer is
self-contained with the required Windows App SDK runtime.

The MSI is currently unsigned, so Windows SmartScreen may ask for confirmation
before installation. The accompanying `.sha256` asset can be used to verify the
download.
