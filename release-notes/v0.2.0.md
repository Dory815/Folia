# Folia 0.2.0

Folia (折笺) is a native Windows Markdown reader and editor built with WinUI 3,
Direct2D, DirectWrite, and C++23. This release strengthens structural editing,
document lifecycle handling, and table interaction while preserving Folia's
source-faithful Markdown model.

## Highlights

- Added conflict-aware document reload. Folia monitors the open file without
  polling, reloads clean documents after external changes, preserves encoding
  and view state, and prompts before replacing unsaved edits. Manual reload is
  available through `F5` and handles replacement, rename, and deletion cases.
- Reworked fenced code and display-math blocks as explicit editor structures.
  Empty blocks can be removed as a unit, code blocks expose an editable language
  selector, Mermaid fences retain their diagram behavior, and boundary editing,
  selection, copy/paste, Delete, Backspace, and undo/redo follow block semantics.
- Added a transactional Markdown formatting command that normalizes document
  structure without replacing the lossless, block-local editing architecture.
- Defined table text and structure boundaries, including precise partial-cell
  selections and predictable copy/paste and structural editing behavior.
- Added deterministic regression coverage for reload races, raw block editing,
  table selections, formatting, shortcuts, and document state restoration.
- Updated application and installer metadata for the `0.2.0` release.

## Installation

Download `Folia-0.2.0-x64.msi` from the assets below and run it for a per-user
installation. Folia supports 64-bit Windows 10 and Windows 11. The installer is
self-contained with the required Windows App SDK runtime.

The MSI is currently unsigned, so Windows SmartScreen may ask for confirmation
before installation. The accompanying `.sha256` asset can be used to verify the
download.
