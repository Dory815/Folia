# Math cancellation candidate (G160)

`math-cancellation-g147.patch` is the full cooperative cancellation candidate. The narrow follow-up `math-cancellation-no-test-hook.patch` removes the checkpoint observer/test callback from that candidate and replaces stage-specific callback tests with real Source getter and public Renderer integration tests. Apply the full candidate first, then this correction patch. The no-hook correction passes `git apply --check` against the composed candidate tree. The focused G163 test-fix patch separately qualifies `folia::math::Property` in the real Source getter restoration guard; it passes `git apply --check` against the current candidate tree.

The observer was originally added to request stop at exact checkpoint counts for deterministic testing. That made each production checkpoint call arbitrary `std::function` code, crossing the product boundary. The correction removes `CheckpointObserverScope`, its thread-local callback, and its dispatch. Production checkpoints now only inspect the active thread-local request's stop token and deadline. It intentionally avoids claims that tests cancel at exact TeX/layout/Scene/serialization stages.

Cancellable APIs use `render(tex, std::stop_token, RenderOptions)`, `renderScene(tex, std::stop_token, RenderOptions)`, and matching `toSvg` overloads for UTF-8/UTF-16. All three arguments are required, preserving existing two-argument brace-initialized options calls. `RenderOptions::deadline` is an optional `steady_clock::time_point`. Preflight cancellation returns `Cancelled` without mutating the Source document and leaves the Renderer reusable. Cancellation observed during an active public render returns `Cancelled` and marks the same Renderer `SessionUnusable` for later calls.

The correction tests use the real Source `textContent` getter in `NativeRenderSession` to request stop during conversion and a large public Renderer input with an active deadline. They assert cancellation and session-use outcomes without pretending to identify an exact checkpoint. Nested request scopes and thread-local isolation are tested through `Request` and `Scope` only. Existing brace-initialized calls are checked for UTF-8/UTF-16 `render`, `renderScene`, and `toSvg`.

Cancellation is cooperative. A currently executing regex operation, synchronous native font callback, allocator, or other indivisible native call cannot be interrupted; it is observed at a later checkpoint. This is not a hard deadline. The change also does not reclaim Renderers or address the separate lifetime bound. No formal files were modified here and no build was run; Root owns the shared G162 build.

The G163 test fix is needed because this translation unit imports `folia.math` but does not bring `folia::math::Property` into unqualified lookup. `RestoreGetter::previous` uses the fully qualified type.
